# Project 1 - Rule-Based AI Chatbot

## Objective
Create a simple rule-based chatbot that responds to predefined user inputs.

## Requirements Covered
- Handles greetings
- Handles exit commands
- Uses if-else decision-making logic
- Runs continuously using a while loop
- Uses basic Python control flow

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in this project folder.
3. Run:

   python chatbot.py

4. Type messages such as:
   - hello
   - how are you
   - what is your name
   - who are you
   - help
   - bye

No external libraries are required.
